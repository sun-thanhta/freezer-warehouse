## WF-05 — Tồn kho & 隔離 (SCR-08 + SCR-10)

Một trang, 3 chế độ xem. Tiêu đề đổi theo chế độ: "Tồn kho đa tiêu chí" / "Cảnh báo cận hạn" / "隔離 / release / scrap".

```
┌─ [1] 隔離 / release / scrap ─────────────────────────────────────────────────────────────┐
│      SCR-08 / SCR-10 · Tồn theo SKU / lô / vị trí / dải nhiệt. Lô 隔離 bị khóa…           │
├──────────────────────────────────────────────────────────────────────────────────────────┤
│ [2] ( Toàn bộ tồn ) ( Cận hạn & quá hạn ) (●隔離 )  │ [3] (●Tất cả dải) (常温) (冷蔵) (冷凍) │
│ [4] ┌───────────────────────────────────────────────────────────────┐                     │
│     │ ✔ LOT-CHI004-A: đã release về kho — có ghi audit.            │ (sau thao tác)      │
│     └───────────────────────────────────────────────────────────────┘                     │
│ [5] ┌────────┬──────────────┬───────────┬──────┬──────────┬───────────┬─────────┬──────────────────────────────┐
│     │SKU     │Lô / truy xuất│Dải / vị trí│Loại  │Hạn dùng  │Còn        │Tồn/nhập │Xử lý (QA) ← chỉ manager ở   │
│     │        │              │           │hạn   │          │           │         │view 隔離; còn lại: NCC       │
│     ├────────┼──────────────┼───────────┼──────┼──────────┼───────────┼─────────┼──────────────────────────────┤
│     │CHI-004 │LOT-CHI004-A  │冷蔵        │‹消費›│2026/10/05│‹2 ngày    │10/10 bag│[6][Lý do (QA)___]            │
│     │カット… │              │C-Q-01     │ (đỏ) │          │(ngưỡng 2)›│         │[7][Vị trí… ▼] (chỉ vị trí    │
│     │        │              │‹隔離›(tím) │      │          │  (cam)    │         │   thường cùng dải: C-01..03) │
│     │        │              │           │      │          │           │         │[8][ Release ] [9][ Scrap ]   │
│     └─5a─────┴─5b───────────┴─5c────────┴─5d───┴─5e───────┴─5f────────┴─5g──────┴─5h───────────────────────────┘
│ Màu nền dòng: tím = đang 隔離 · đỏ = quá hạn · cam = cận hạn.                               │
│ Cột "Dải / vị trí" có thêm ‹sai dải›(đỏ) khi vị trí khác dải của SKU.                        │
│ Rỗng: "Không có lô phù hợp."                                                              │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

Chế độ "Toàn bộ tồn" / "Cận hạn": cột cuối là tên NCC, không có [6]–[9].
Cột "Còn": `‹Quá hạn n ngày›` (đỏ) · `‹n ngày (ngưỡng m)›` (cam) · `n ngày` (chữ thường).
Lô gạo/bò: dưới số lô có mã truy xuất (tím) và nhãn lane.
